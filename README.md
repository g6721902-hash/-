# MaaApp – تطبيق ماء

مشروع Android تجريبي لتطبيق توصيل ماء.

## إخراج APK من الموبايل باستخدام GitHub Actions
1. أنشئ مستودع GitHub جديد باسم `MaaApp`.
2. ارفع كل محتويات هذا المشروع إلى المستودع، ثم اجعل الفرع الرئيسي `main`.
3. افتح تبويب **Actions**.
4. اختر **Build Maa APK** ثم **Run workflow**.
5. بعد نجاح البناء افتح التشغيل الناجح، ثم قسم **Artifacts** وحمّل `Maa-debug-apk`.
6. فك الضغط وستجد `app-debug.apk`.

هذا الإصدار يعمل كتجربة محلية. ربط Firebase الحقيقي يحتاج إضافة ملف `google-services.json` للمشروع لاحقًا.
